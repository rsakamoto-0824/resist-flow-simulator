# Resist Flow Lab

半導体リソグラフィーで用いるレジストの、塗布・蒸発・リフロー・細隙への充填を調べる MATLAB アプリです。Windows 向けのスタンドアロン配布を想定し、材料、形状、工程条件を変更して比較できます。

初版は次の 3 モードを備えています。サンプル条件は仮想材料であり、実レジストの予測には物性値と実測値による校正が必要です。**この Mac にある MATLAB R2022b で数値テスト 31 件が合格しました。MATLAB Compiler は未導入・ライセンスなしで、Windows EXE は未生成です。** 前回の「MATLAB がない」という記載は、PATH 上のコマンドだけで判定した誤りでした。

この Mac ですぐ試すための独立した `.app` は [Mac テスト版](macos/README.md) を参照してください。同じ物理式を用いた JavaScript 計算部を macOS ネイティブのウィンドウへ組み込んだもので、MATLAB のコンパイル版ではありません。

| 計算モデル | 調べられること | 主な前提 |
| --- | --- | --- |
| 2D リフロー・段差平坦化 | 表面張力による面内の膜厚変化、浅く滑らかな基板形状の影響 | 薄いニュートン流体、小さい勾配、周期境界、一定温度 |
| 均一膜スピン塗布・蒸発 | 回転、溶剤蒸発、濃縮による平均膜厚と粘度の変化 | 面内で均一な膜、一定回転数、一定温度 |
| 細隙への充填 | 濡れと外部圧力による充填長さ・充填時間 | 平行平板の開放スリット、一定粘度・接触角、十分な液体供給 |

## MATLAB で起動

MATLAB R2023b 以降でプロジェクトのフォルダを開き、コマンドウィンドウで実行します。

```matlab
addpath('matlab');
ResistFlowApp
```

ソースから実行する場合、MATLAB Compiler は不要です。計算にネット接続、サーバー、API キー、環境変数は必要ありません。入力データは端末内で処理します。

## Windows 用の配布物を作成

作成する人には、**Windows 上の MATLAB R2023b 以降と MATLAB Compiler** が必要です。配布先には MATLAB のライセンスは不要ですが、ビルド時と同じリリースの対応する MATLAB Runtime が必要です。Mac で Windows の EXE を作成する手順ではありません。[MathWorks の standaloneApplication](https://www.mathworks.com/help/compiler/compiler.build.standaloneapplication.html)、[MATLAB Runtime](https://www.mathworks.com/help/compiler/matlab-runtime.html)

Windows の MATLAB で次を実行します。

```matlab
addpath('matlab');
outputDirectory = buildStandalone;
```

`buildStandalone` は自動テストを実行し、成功した場合に `dist/windows/<作成日時>/` へ EXE とインストーラーを作成します。標準では MATLAB Runtime を同梱するため、Runtime の取得・同梱準備がビルド環境に必要です。配布先で Runtime をダウンロードする方式は `buildStandalone('web')` で指定できます。[R2023b のインストーラー仕様](https://www.mathworks.com/help/releases/R2023b/compiler/compiler.package.installer.html)

作成したインストーラーを対象 Windows 11 PC で実行し、3 モードの計算、条件の保存・復元、CSV 出力、画像保存を確認してから配布してください。Runtime 同梱はファイルサイズが大きくなります。会社での起動・利用にエージェント AI は必要ありません。

## 基本操作

1. 計算モデルを選択します。モデル変更時は、そのモデル向けのサンプル条件に切り替わります。
2. 形状、材料、温度、工程を入力します。各入力欄に単位を表示しています。
3. 計算を実行し、膜厚または充填形状、中央断面、時系列を確認します。
4. 時間スライダーで保存された計算時刻を選びます。
5. 現在の結果を比較用に保持し、条件を変更して再実行すると、1 件の基準結果と比較できます。
6. 条件は JSON、計算結果は CSV、表示図は PNG で保存します。

立体表示の高さと断面の表面高さは「基板高さ + 液体膜厚」、色は「液体膜厚」です。スピン塗布モードの面は均一膜の模式図で、面内分布の計算結果ではありません。充填モードは 1 本のスリットに入る液体の先端位置を表示します。

### 任意の初期膜厚を読み込む

2D モードでは 16 × 16、32 × 32、64 × 64 のいずれかの数値行列を初期膜厚 CSV として読み込みます。

- ヘッダー、座標列、単位文字を含めず、カンマ区切りの数値だけにします。
- 各数値は液体膜厚で、単位は µm です。基板高さや自由表面高さではありません。
- 各値は正の有限数とし、最小膜厚 0.01 µm を上回る範囲にします。
- 左から右が x 方向、上から下が y 方向です。
- 周期境界のため、左右端と上下端は隣接します。接続部が滑らかになる分布を用意してください。

2D モードの膜厚 CSV 出力は、上記の条件を満たせば新たな初期条件として利用できます。条件をまとめて再利用したい場合は JSON を保存してください。比較結果はアプリ内で保持するため、閉じる前に必要な結果を保存します。

基板高さも「基板高さ CSV を読み込む」から同じ形式・単位で指定できます。基板高さには負の値も使えます。膜厚と基板には同じ格子数の行列を使い、各 CSV は 1 MB 以下にします。異なる格子数を読み込むと、先に読み込んだ形状データは解除されます。

充填モードの結果は時系列 CSV に保存します。初期時刻の駆動がある先端速度と、充填できない条件の充填時間は `NaN`（このモデルでは未定義）です。

## 結果の確認

薄膜モードでは平均膜厚、最小・最大膜厚、CV（標準偏差 / 平均 × 100）、数値的な体積収支残差を確認できます。充填モードでは先端位置、充填率、駆動圧力、充填時間を確認します。収支残差が小さくても、実際の工程を正しく再現しているとは限りません。

実材料へ適用する際は、まず粘度と表面張力を実測条件に合わせます。スピン塗布では固形分を**体積比**で入力し、蒸発係数と濃縮粘度係数を独立した膜厚・濃度データで校正してください。質量比をそのまま代入しないでください。

数値精度は、同じ物理条件で格子数を 16 → 32 → 64、時間刻みを標準 → 1/2 → 1/4 と変えて確認します。2D モードの許容時間刻みは格子幅の 4 乗に比例するため、格子を細かくすると計算量が大幅に増えます。まず 16 または 32 から試してください。

## 対象外と停止条件

薄膜モードでは急峻な側壁、接触線、ウェハ端のエッジビード、滴下や液滴合体を扱いません。充填モードでは閉じ込め気体、動的接触角、初期慣性、満充填後の出口流れを扱いません。いずれも非ニュートン性、露光・現像反応、乾燥後の弾性、温度分布は対象外です。完全な三次元流体計算ではありません。

2D モードの蒸発は一様な膜厚減少で、溶剤濃度と粘度変化を連成しません。最小膜厚 0.01 µm 付近で計算を停止します。スピン塗布モードは固形分率 0.99 付近で停止し、乾燥膜の物性を予測しません。数値異常や計算量の上限でも停止し、理由を画面に表示します。

## 構成と確認状況

MATLAB 標準の数値計算と UI を使用します。ネイティブのテストは `matlab/tests/`、JavaScript による別実装の数値参照は `verification/js/` にあります。数値参照の合格は MATLAB アプリや EXE の動作確認にはなりません。確認範囲は [検証記録](verification/README.md) に記録しています。

テストだけを実行する場合は次のコマンドを使います。

```matlab
addpath('matlab');
results = runtests('matlab/tests');
assert(all([results.Passed]));
```
